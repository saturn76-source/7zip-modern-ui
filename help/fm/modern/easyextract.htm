Easy Extract

Easy Extract is the quickest way to extract archives. Use the Easy Extract toolbar button or Tools > Easy Extract.

Archives selected in a folder

  1. Select one or more archive files in the file list.
  2. Click Easy Extract. The Easy Extract window opens.
  3. The Extract to path ends with *. The * stands for each archive's name: every archive is extracted to its own folder, named like the archive (without the extension), next to the archive. You can change the path or choose another folder with the ... button.
  4. Click OK.

If Open the extracted files folder when done is checked, the extracted folders are opened in File Explorer when extraction is finished.

Only archive files are extracted. Other selected files and folders are ignored. If no archive file is selected, 7-Zip shows the message "You must select one or more archive files".

Inside an archive

When you have opened an archive in 7-Zip, Easy Extract always extracts the whole archive, not only the selected items, to a folder named like the archive.
