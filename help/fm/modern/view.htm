Color Theme, Zoom and View

Color Theme

Choose the colors in View > Color Theme:

  • Light - light colors.
  • Dark - dark colors for the window, menus, file list and dialog boxes.
  • Auto (as Windows) - follows the Windows setting "Choose your app mode". This is the default.

File list zoom

You can make the file list bigger or smaller, from 50% to 400%:

Command Shortcut
View > Zoom In Ctrl+Plus, or Ctrl+mouse wheel up
View > Zoom Out Ctrl+Minus, or Ctrl+mouse wheel down
View > Reset Zoom Ctrl+0

The zoom changes the text, icons and column titles of the file list. The zoom level is saved.

Status bar buttons

At the right end of the status bar there are buttons:

  • -, 100%, + - zoom out, reset zoom (the button shows the current zoom), zoom in.
  • Details and Large Icons - switch the view of the file list.

Size in KB

View > Size in KB shows the Size and Packed Size columns in kilobytes (for example "1 112 KB") instead of bytes. It is on by default.

".." item

The ".." item (up one level) in the file list is off by default. You can turn it on in Options (Settings page, Show ".." item). You can always go up one level with Backspace or the up button left of the path box.
