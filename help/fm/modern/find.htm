Find Files

Open the Find window with the Find toolbar button, Edit > Find... or Ctrl+F.

Find window

Option Description
File name The name to search for. You can use wildcards: * (any characters) and ? (one character). For example: *.zip, report*.
Search in The folder to search in. It starts with the current folder. You can type another path or choose a folder with the ... button.
Search in subfolders Search also in all subfolders.
Search in archives only Look inside archive files and search the files they contain.

Searching

The search runs in the background. A progress window shows the folder being searched, the number of files found and the list of found files. Press Cancel or Esc to stop the search.

Results

When the search is finished, the results window lists the found files with their folders. Select a file and press Enter (or OK): 7-Zip opens its folder (or the archive that contains it) and selects the file.

If very many files are found, only the first ones are shown. Find works in folders on disk and in archives.
