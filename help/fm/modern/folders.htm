Folders, File Types and Drag and Drop

Quick folders

The path box drop-down list contains quick links to your Desktop, Downloads, Pictures and Videos folders, with their Windows icons.

Top level list

The root folder (View > Open Root Folder, or the \ key) shows these items, always in this order:

  • Computer: computer's disks
  • Desktop, Downloads, Documents, Videos, Pictures: your user folders
  • Network
  • \\.: the folder for low-level access to disks (administrator rights are required)

File type icons

7-Zip contains its own icons for 35 archive types, for example 7z, zip, rar, iso, tar, gz, xz, cab and wim. When you associate file types with 7-Zip (Options, System page), these icons are shown in File Explorer, and 7-Zip is added to the Open with list.

Drop to open

Drag one archive from File Explorer and drop it on the file list of a normal folder: 7-Zip opens the archive. (Dropping several files, or dropping into an opened archive, works as in the original 7-Zip.)
